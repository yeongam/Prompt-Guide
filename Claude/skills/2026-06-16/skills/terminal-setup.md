# /terminal-setup — Terminal Configuration

- Slug: `terminal-setup`
- Cmd: `/terminal-setup`

- Trigger: User wants to configure terminal rendering, GPU acceleration, or IDE terminal integration.

1. Run `/terminal-setup` to open interactive config wizard.
2. Adjust font, GPU acceleration, rendering mode.
3. Settings saved to user config; apply immediately.

## Output

Terminal config updated; confirms active settings.
