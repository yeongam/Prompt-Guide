---
name: dataviz
description: Guidance for any chart, graph, dashboard or KPI tile in any medium. Load before writing chart code or picking colors.
---
Cmd: `/dataviz`
1. Form: compare→bar, trend→line, part-of-whole (≤5)→stacked bar, distribution→histogram, correlation→scatter.
2. Color: categorical ≤6 hues; sequential = one hue light→dark; diverging = two hues around neutral; validate contrast in light+dark.
3. Marks: direct labels over legends; start bar axes at 0; no 3D, no dual axes unless asked.
4. Interaction: tooltip with exact value; same color = same series across views.
