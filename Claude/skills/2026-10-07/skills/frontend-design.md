---
name: frontend-design
description: Distinctive, non-templated UI design. Use when building or reshaping UI.
---
- Identify subject, audience, primary job; brief wording overrides all defaults.
- Plan first (compact): 4-6 named hex colors, type roles, layout (ASCII wireframe, alignment), principles. Check plan isn't a generic default; revise.
- Avoid tells: cream+serif+terracotta, black+acid accent, hairline broadsheet, identical rounded cards+gray shadows+gradients, ALL-CAPS eyebrows, middot meta, `→` on links, single-word headline accents, fake 01/02/03 numbering.
- Type: 1-2 distinct families, deliberate scale, lines <80ch.
- Motion: one orchestrated moment; otherwise respond to user action only.
- One bold element; rest quiet. Floor: responsive, focus-visible, reduced-motion, accessible contrast.
- Copy: user-perspective, active voice, sentence case, specific CTAs ("Save changes"), errors say what failed + fix.
- Watch CSS specificity collisions between sections.
