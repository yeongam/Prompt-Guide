---
name: feature-dev
description: Guided feature build: explore, clarify, design, implement, review.
---
Phases (track with todos):
1. Discovery: restate request; clarify if vague.
2. Explore: 2-3 parallel explorer agents (similar features, architecture, UI/tests); read their key files.
3. Clarify: list all ambiguities (edge cases, errors, scope, compat); wait for answers (give a recommendation if "whatever").
4. Design: 2-3 architect agents (minimal / clean / pragmatic); recommend one; user picks.
5. Implement only after approval; follow repo conventions.
6. Review: 3 reviewers (simplicity/DRY, correctness, conventions); user decides fixes.
7. Summarize: built, decisions, files, next steps.
Automated runs: no user to ask — pick the recommended option and record assumptions.
