# frontend-design
Distinct, subject-specific UI; no template defaults.
1. Identify subject, audience, primary job (propose if brief silent). Brief wins over these rules.
2. Plan first: palette 4-6 named hex; 1-2 deliberately chosen typefaces + scale; layout (ASCII sketch, alignment); principles. Check plan isn't the generic default; revise.
3. Avoid tells: cream+serif+terracotta; black+acid accent; broadsheet hairlines; identical rounded shadowed cards; ALL-CAPS eyebrows, middle-dot meta, "WORD — frag", mono labels, trailing "→", single-word headline accent, fake 01/02/03 numbering, scattered fade-up motion.
4. Hero = most characteristic thing of the subject. Lines <80ch. One bold element, rest quiet; motion only orchestrated or action-driven.
5. Floor: responsive, visible focus, reduced-motion, accessible contrast. Watch CSS specificity clashes.
6. Copy: user language, active voice, sentence case, CTA names the action, errors say what/how to fix.
