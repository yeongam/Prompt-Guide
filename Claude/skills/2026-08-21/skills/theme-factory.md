- Slug: `theme-factory`

## Trigger

Toolkit for styling artifacts with a theme.

## Detail

These artifacts can be slides, docs, reportings, HTML landing pages, etc. There are 10 pre-set themes with colors/fonts that you can apply to any artifact that has been creating, or can generate a new theme on-the-fly.

## Defaults

Procedure, token policy, and compatibility rules are shared; see `catalog.json` -> `defaults`.
