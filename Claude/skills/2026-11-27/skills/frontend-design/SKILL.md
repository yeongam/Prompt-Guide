# Frontend Design
Src: claude-plugins-official/frontend-design@0fbfda5a91f4
1. Ground in the subject: palette, type, imagery derived from the domain, not defaults.
2. Pick one clear aesthetic direction; commit to it (type pairing, spacing scale, color tokens).
3. Plan → check against brief → build → critique screenshot → fix.
4. Restraint: remove decoration that doesn't serve content; real copy over lorem.
5. Accessibility: contrast, focus states, responsive at phone width.
