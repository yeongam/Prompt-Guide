## 2.1.152

- `/code-review --fix` now applies review findings to your working tree after the review
- Skills can now set `disallowed-tools` in frontmatter to remove tools while the skill is active
- Added `/reload-skills` command to re-scan skill directories without restarting
- `SessionStart` hooks can now return `reloadSkills: true` to re-scan skill directories
- `SessionStart` hooks can now set the session title via `hookSpecificOutput.sessionTitle`
- Added `MessageDisplay` hook event that lets hooks transform or hide assistant message text
- Added `pluginSuggestionMarketplaces` managed setting for org marketplace allowlists
- `claude plugin marketplace remove` now accepts `--scope user|project|local`
- Claude Code now switches to `--fallback-model` when primary model is not found
- Auto mode no longer requires opt-in consent
- Vim mode: `/` in NORMAL mode now opens reverse history search
- `/usage` breakdown now includes large session files with streaming read
- Thinking summaries stay readable for at least 3 seconds, render as markdown, cap at 10 lines
